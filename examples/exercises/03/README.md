# Your first live preview

## Objective

Connect a pure function to a running HTTP application.

1. Run tests to see the failing message expectation.
2. Change `message.mjs` to return `Hello, Icode Workshop!`.
3. Run tests again.
4. Select **Preview**, then **Start app** to see the live page.
5. Stop and start the app after editing server code to load your changes.

`server.mjs` owns the HTTP server; `message.mjs` owns the value under test. The preview runs on loopback and stops when you switch labs. The reference solution remains read-only.
